# 简单的 5+ App 示例

这是一个非常基础的 5+ App，旨在演示一个 "Hello World" 程序。

## 如何使用

1.  **环境准备**:
    *   下载并安装 [HBuilderX](https://www.dcloud.io/hbuilderx.html)。HBuilderX 是 DCloud 官方推荐的 5+ App 开发 IDE。

2.  **导入项目**:
    *   打开 HBuilderX。
    *   点击菜单栏的 `文件` -> `导入` -> `从本地目录导入`。
    *   选择这个项目的根目录。

3.  **运行项目**:
    *   在 HBuilderX 的项目管理器中，右键点击项目。
    *   选择 `运行` -> `运行到手机或模拟器` -> 然后选择你的设备。
    *   或者，你也可以选择 `运行` -> `运行到浏览器` -> `内置浏览器` 来快速预览。

## 文件结构

*   `manifest.json`: 应用的配置文件，包含了应用的 ID、名称、版本、图标、启动页面等信息。
*   `index.html`: 应用的主页面，也是启动时加载的页面。
*   `css/style.css`: 用于定义 `index.html` 页面样式的 CSS 文件。

## 注意事项

*   你需要一个有效的 DCloud 开发者账号来使用云打包等服务。
*   这个项目非常基础，你可以基于此项目进行扩展，添加更多的页面和功能。
